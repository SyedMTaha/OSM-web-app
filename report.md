OpenStreetMap (OSM) is a free and community-built geographic database containing map information from around the world. Unlike proprietary services such as Google Maps, OpenStreetMap provides openly available map data that can be used by developers while following its licensing, attribution, and usage policies. In a web application, OSM map imagery is commonly displayed through map tiles, which are small square images loaded together to create the complete map at a selected zoom level. Leaflet is a lightweight JavaScript mapping library that can display these tiles and provide interactive features such as zooming, panning, markers, and popups.

Markers are points placed on a map using latitude and longitude coordinates. They can represent sample assets, incidents, or other locations and can display additional information through popups. Geocoding is the process of converting an address into geographic coordinates, while reverse geocoding converts coordinates back into an address. OpenStreetMap requires appropriate attribution, such as “© OpenStreetMap contributors,” and developers must follow the applicable tile usage policy. These rules help ensure that the service is credited properly and that shared infrastructure is not abused. For this project, only synthetic sample locations are used to avoid exposing private addresses or live-target information.
