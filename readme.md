# OpenStreetMap Integration in Web App

## Project Overview

This project demonstrates the integration of OpenStreetMap
with Leaflet.js in a web application.

The application displays five synthetic security asset
locations using markers and interactive popups.

## Technologies

- HTML5
- CSS3
- JavaScript
- Leaflet.js
- OpenStreetMap

## Features

- Interactive OpenStreetMap
- Five synthetic security asset markers
- Marker popups
- Asset selection dropdown
- Map fly-to interaction
- Browser Geolocation API
- Responsive mobile layout

## Sample Data

All locations used in this project are synthetic.

No private addresses, real individuals, or live security
targets are represented.

## Geolocation

The optional "Locate Me" feature uses the browser
Geolocation API to obtain coordinates after user permission.

No address database or bulk geocoding is used.

## AI Usage

AI assistance was used to help understand the assignment,
structure the HTML/CSS/JavaScript implementation, and
prepare sample code and documentation.

The implementation was reviewed and tested manually.

## Conclusion

This project demonstrates how OpenStreetMap and Leaflet.js
can provide an interactive, open-map solution without
requiring a paid mapping API key.
